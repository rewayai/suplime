# installs. `pip install suplime` deliberately does not pin these — it accepts any
# pyannote.audio 4.x — but checkpoint compatibility is not a promise across arbitrary
# torch/torchaudio releases:
#
#   * the segmentation model is rebuilt from a torchaudio bundle *config*
#     (`torchaudio.pipelines.WAVLM_*._params`) and its state_dict has to match the module
#     layout `torchaudio.models.wavlm_model()` produces in the installed version;
#   * `_params` and `_normalize_waveform` are private torchaudio attributes. suplime raises
#     a clear TypeError if they disappear (see suplime.train.load_wavlm and
#     tools/convert_checkpoints.py) rather than silently building the wrong model.
#
# If you need to reproduce a published number exactly, install from this file.
#
#   pip install -r requirements-tested.txt && pip install -e .
